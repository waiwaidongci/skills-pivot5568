# 002 月末关账表结构

应用启动时以 SQLAlchemy 模型补建下列新表，已有数据表不受影响。

- `channel_batches` 渠道整月批次：渠道、月份、入库时间和对应数据批次。同一渠道同一月份可多次入库，关账取关账时点前最后一批。
- `closing_config` 单行配置：关账起月，自该月起逐月关账补算。
- `closings` 每月关账记录：月份唯一，记录关账时点、状态（locked / closed / incomplete）、缺数渠道和合算运行。先提交锁定，再合算，中断后续跑沿用锁定批次，重试不重复生成。
- `closing_sources` 关账锁定来源：每月每渠道一行，指向锁定的渠道批次，缺渠道留空。
